# SexNote i18n

Language packs (`tl_*.zip`) for SexNote, published as [GitHub Releases](../../releases).

## Current release: `tl-0.25.0-r7`
- `tl_chinese.zip` — Simplified Chinese
- `tl_japanese.zip` — Japanese
- `tl_persian.zip` — Persian / Farsi (RTL)
- `tl_german.zip` — German
- `tl_portuguese.zip` — Portuguese (PT Europe)

Fonts ship inside the game build (`gui/fonts/`). Zips contain only `tl/<lang>/` overlays.
