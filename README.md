# SexNote i18n

Language packs (`tl_*.zip`) for SexNote, published as [GitHub Releases](../../releases).

## Current release: `tl-0.25.0-r5`
- `tl_chinese.zip` — Simplified Chinese (~20.5k strings, `translate chinese strings:`)
- `tl_japanese.zip` — Japanese (~20.4k strings, `translate japanese strings:`)
- `tl_persian.zip` — Persian / Farsi (~20.3k strings, `translate persian strings:`, RTL)

Fonts ship inside the game build (`gui/fonts/`). Zips contain only `tl/<lang>/` overlays.
